# বিআর ১৯ — BR 19

বাংলাদেশ রেলওয়ের ট্রেনের সময়সূচি, রুট, দেরির ইতিহাস আর লাইভ দেখার লিংক — বাংলায়।
ফোনের ব্রাউজারে চলে, হোম স্ক্রিনে রাখা যায়। প্লে স্টোর লাগে না।

**লাইভ লিংক:** Render-এ ডেপ্লয় করার পর এখানে বসবে।

## কী আছে

- **ট্রেন খুঁজুন** — নাম বা নম্বর দিয়ে (যেমন ৭৩৫ অগ্নিবীণা, ৩৫৪ ময়মনসিংহ লোকাল)
- **একটি ট্রেনের খবর** — রুট, ছাড়া/পৌঁছানোর সময়, সময়সূচি অনুযায়ী আনুমানিক অগ্রগতি,
  শেষ পার হওয়া স্টেশন, পরের স্টেশন + কত মিনিট বাকি, গত ৭ দিনের দেরির হিসাব,
  গড় দেরি ধরে আনুমানিক পৌঁছানোর সময়, পুরো রুটের সময়সূচি
- **চলমান সব ট্রেন** — ২০০+ ট্রেনের তালিকা, নাম/নম্বর/স্টেশন দিয়ে খোঁজা যায়
- **স্টেশন দিয়ে খুঁজুন** — কোন স্টেশনে কোন ট্রেন থামে, কয়টায়
- **রিফ্রেশ বোতাম** — দেখার সময় (ঢাকা) সবসময় দেখানো হয়

## তথ্যের উৎস — সত্যি কথাটা

তথ্য আসে **TrainKothai.com**-এর পাবলিক পাতা থেকে (সময়সূচিতে পাবলিক BR ডেটা,
লাইভ অবস্থান যাত্রীদের শেয়ার করা — অফিসিয়াল বাংলাদেশ রেলওয়ে ফিড **নয়**)।

**সীমা (গুরুত্বপূর্ণ):** ট্রেনের একদম সরাসরি অবস্থান/গতি/বর্তমান দেরি ট্রেনকোথাইয়ের
লাইভ এপিআই (`/api/v1/live/track/<নম্বর>`) থেকে আসে, যেখানে ঢুকতে Cloudflare
Turnstile যাচাই (ব্রাউজারে মানুষের পরীক্ষা) লাগে। সার্ভার থেকে সেটা করা যায় না —
সার্ভার থেকে লাইভ এপিআই `401 {"error":"pass_required"}` দেয় (পরীক্ষা করা:
2026-11-10)। তাই এই অ্যাপ সার্ভার থেকে **সরাসরি লাইভ অবস্থান বানিয়ে দেখায় না**।
প্রতিটি ট্রেনের পাতায় **“ট্রেনকোথাইতে লাইভ দেখুন”** বোতাম আছে — চাপ দিলে
ব্যবহারকারীর ব্রাউজারে ট্রেনকোথাইয়ের লাইভ পাতা খুলবে, সেখানে সরাসরি অবস্থান,
গতি আর দেরি দেখা যাবে। অ্যাপে যা “আনুমানিক” লেখা, তা সময়সূচি দিয়ে হিসাব করা —
কখনোই সরাসরি লাইভ নয়।

## চালানো

```bash
npm install
npm start          # http://localhost:3000
```

তথ্যের স্ন্যাপশট বানাতে (২০৭ ট্রেনের সময়সূচি — ভদ্রভাবে, ১.২ সেকেন্ড বিরতিতে):

```bash
npm run scrape     # data/trains.json লেখে
```

## ডেপ্লয় (Render, ফ্রি)

1. এই রেপো GitHub-এ পুশ করুন (`shoshikola19-debug/br-19`)।
2. Render Dashboard → **New +** → **Blueprint** → রেপোটি বেছে নিন।
   `render.yaml` পড়ে ফ্রি Web Service বানাবে (`npm install` → `npm start`)।
3. ফ্রি টিয়ার ~১৫ মিনিট অলস থাকলে ঘুমিয়ে যায়; ঘুম থেকে উঠতে প্রথম লোডে
   ৩০-৬০ সেকেন্ড লাগতে পারে — এটা স্বাভাবিক।

## ফাইল

- `server.js` — Express সার্ভার + `/api/trains`, `/api/train/:number`, `/api/station`, `/api/health`
- `public/` — বাংলা ফ্রন্টএন্ড, `logo.webp` (গাঢ় নীল পুরো ট্রেন, রেল সেবার লোগোর কপি নয়)
- `tools/scrape_trainkothai.py` — সময়সূচির স্ন্যাপশট বানানোর স্ক্রিপ্ট
- `data/trains.json` — স্ন্যাপশট (তৈরির সময় ভেতরে লেখা থাকে)
- `render.yaml` — Render ব্লুপ্রিন্ট
